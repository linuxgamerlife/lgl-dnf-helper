LGL DNF Helper

LGL DNF Helper is a read-only guide to the RPM packages on your Fedora system. Find what a package needs, what needs it, which files and config it owns, where it came from, and how risky it may be to remove.

It reads information through dnf5 and rpm; it never installs, removes, or updates packages. Run it as your normal user, not with sudo.

The app follows your desktop's GTK theme, including light or dark mode, the accent colour, and the monospace font. Theme changes apply while the app is open.

Getting started

  1. Type a package name, command, capability, partial name, or file path in the search field.
  2. Press Enter or choose Search.
  3. Choose a result to open its details.

Header bar

  • Reset clears the search, results, selected package, and log.
  • The status chip shows READY, QUERYING, ERROR, or SETUP NEEDED.

The main menu at the right of the header bar provides Clear Log, Use System Title Bar, Help, About LGL DNF Helper, and Quit. Tap Alt or press F10 to open or close it from the keyboard.

Use System Title Bar lets your compositor draw the title bar. Choose it again, or press Ctrl+Shift+M, to return to the app title bar. The app remembers the choice.

Search

Search combines these matches, in this order:

  1. An installed package with exactly that name.
  2. Installed and available packages that provide that capability or command. Searching dnf finds the installed dnf5.
  3. Package names that contain the text. Searching kineticwe also finds kineticwe-noctalia and kineticwe-greeter.

Source packages are left out. A search beginning with / looks up the installed package that owns that file.

Results

  • Installed Packages lists matches installed on this system.
  • All Packages lists every match with its version and architecture. Identical builds appear once.

Searching only fills these lists. Choose a result, or select it and press Enter, to show its details.

Package details

The Selected Package card shows the package name, full version, and badges that sum it up.

Package badges

  • Installed: installed on this system.
  • Available: offered by an enabled repository, but not installed.
  • Third-party: from outside Fedora's own repositories, such as COPR, RPM Fusion, or a vendor repository.
  • System-sensitive: a core system package. Take extra care before changing it.

An installed package also shows why DNF installed it:

  • User: explicitly installed and kept until you remove it.
  • Dependency: needed by another package; it may become an autoremove candidate.
  • Weak Dependency: recommended by another package; it may become an autoremove candidate.
  • Group: installed as part of a package group.
  • External User: installed by something other than DNF, such as rpm or a software centre.

Tables

Click a column heading to sort by it and drag its edge to resize it. Hover over a long value to see it in full.

Right-click a row, or press Menu or Shift+F10, to copy its cell, row, or table. URL rows can open in your browser, and path rows can open their containing folder.

When DNF5 is missing

If dnf5 is not installed, the app opens a Setup tab and disables search. Install the tools with sudo dnf install dnf5 rpm, then start the app again.

Queries use DNF's cached metadata and do not download anything. If results look out of date, refresh the cache with sudo dnf makecache.

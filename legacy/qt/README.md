# Archived Qt 6 implementation

This directory contains the Qt 6 implementation that was replaced by the GTK 4
application in version 2.0.0. It is retained as historical reference only.

The active application source is in the repository root: `src/`, `data/`, and
`tests/`. The root CMake build, CI workflow, RPM package, and source RPM build
only that GTK implementation. Do not add new features or fixes here.
